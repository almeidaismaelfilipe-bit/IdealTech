# IdealTech
IdealTech é uma plataforma que auxilia consumidores na escolha de produtos eletrônicos e eletrodomésticos, apresentando informações técnicas, preços, condições de pagamento e uma avaliação própria de custo-benefício. O sistema busca ajudar o usuário a encontrar produtos que atendam às suas necessidades sem gastar mais do que o necessário.
